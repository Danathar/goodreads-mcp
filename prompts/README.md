# Prompts

Reusable prompts for working on and with this server. Each file is a prompt
you can paste into an agent; they encode the repo-specific context that's easy
to get wrong. Repo conventions live in [AGENTS.md](../AGENTS.md).

| prompt | use when |
|---|---|
| [`diagnose-parse-regression.md`](diagnose-parse-regression.md) | a tool returns empty/wrong data and you suspect Goodreads changed something |
| [`add-discovery-tool.md`](add-discovery-tool.md) | adding a new GraphQL-backed tool |
| [`research-a-book.md`](research-a-book.md) | using the server (not editing it) to research a book |
