## Setup: one row per PR

Shell function used by the PR-side commands. It prints one tab-separated row
per pull request numbered ≤ 278: number, `merged`/`closed`, author login,
branch, the `— hive: ` line (spaces turned to `_`, `-` if none), and `closes` if
a body line starts with `Closes`/`Fixes`/`Resolves` followed by `#n`.

```bash
export LC_ALL=C   # fixed sort order, so the output below is the output you get
pulls() {
  gh api --paginate 'repos/Danathar/goodreads-mcp/pulls?state=all&per_page=100' --jq '
    .[] | select(.number <= 278)
    | (.body // "" | split("\n")) as $lines
    | [.number,
       (if .merged_at != null then "merged" else "closed" end),
       .user.login,
       .head.ref,
       ($lines | map(select(startswith("— hive: "))) | .[0] // "-" | gsub(" "; "_")),
       (if ($lines | map(test("^(closes|fixes|resolves) #[0-9]+"; "i")) | any) then "closes" else "-" end)]
    | @tsv'
}
pulls > /tmp/pulls.tsv
```
