## Review findings, the 20 merged PRs numbered #101–#132

| | |
|---|---|
| PRs with at least one Codex finding | 3 (#125, #127, #128) |
| inline findings | 5 (2, 2 and 1) |
| findings embedded in a review body | 0 |

```bash
for n in $(gh pr list --repo Danathar/goodreads-mcp --state merged --limit 500 --json number \
             --jq '.[] | select(.number >= 101 and .number <= 132) | .number'); do
  inline=$(gh api "repos/Danathar/goodreads-mcp/pulls/$n/comments" \
    --jq '[.[] | select(.user.login | contains("codex"))] | length')
  body=$(gh api "repos/Danathar/goodreads-mcp/pulls/$n/reviews" \
    --jq '[.[] | select(.user.login | contains("codex")) | .body | scan("P[0-3] Badge")] | length')
  echo "#$n inline=$inline body=$body"
done
```

`docs/metrics.md` warns that findings can arrive in a review body as well as
inline, and that its one-PR command counts only the inline ones. The loop
counts both: every Codex finding carries a `P0`–`P3` badge, wherever it is
posted. None of the 20 review bodies carried one, so the inline count is the
total.
